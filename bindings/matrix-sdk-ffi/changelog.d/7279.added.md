`WidgetCapabilities` gained the `rtc_livekit_get_token` and `rtc_livekit_delegate_delayed_leave` fields, which
allow a widget to obtain a LiveKit SFU token from, and delegate a MatrixRTC delayed leave event to, the homeserver
([MSC4533](https://github.com/matrix-org/matrix-spec-proposals/pull/4533)). Both are granted by
`get_element_call_required_permissions`.
