Add `Client::grant_login_with_qr_code_support()` for an existing client that
wants to grant a login to a new client, and `Client::login_with_qr_code_support()`
for a new client that wants to log in. They return a `QrCodeLoginSupport` record
which says whether scanning and generating a QR code are supported, or an error
if the support can't be fetched from the servers.
