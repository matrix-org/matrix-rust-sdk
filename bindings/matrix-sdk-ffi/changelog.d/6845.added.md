Add `Client::discover_rtc_transports`, which returns the MatrixRTC transports advertised by the
homeserver (MSC4143), with a fallback to the well-known `m.rtc_foci` unless well-known discovery
was disabled with `ClientBuilder::disable_well_known_lookup`. Transports are exposed as the new
`RtcTransport` enum, with a `LiveKit` variant and a `Custom` variant carrying the raw JSON for
transport types the SDK doesn't know about.

Add `ClientBuilder::disable_well_known_lookup`, which disables every `.well-known/matrix/client`
lookup, including the homeserver discovery performed by `ClientBuilder::build`. The homeserver
must then be given with `ClientBuilder::homeserver_url`. `ClientBuilder::server_name` and
`ClientBuilder::username` can only be resolved through the well-known, so `ClientBuilder::build`
fails with the new `ClientBuildError::WellKnownLookupDisabled` variant.
