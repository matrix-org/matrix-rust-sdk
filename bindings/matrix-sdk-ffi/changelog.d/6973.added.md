Added `Room::sendDelayedEvent`, `Room::sendDelayedStateEvent` and `Room::updateDelayedEvent` for delayed events
([MSC4140](https://github.com/matrix-org/matrix-spec-proposals/pull/4140)), and `Room::sendStickyDelayedEvent` to send a
delayed event that becomes sticky ([MSC4354](https://github.com/matrix-org/matrix-spec-proposals/pull/4354)) once sent.
