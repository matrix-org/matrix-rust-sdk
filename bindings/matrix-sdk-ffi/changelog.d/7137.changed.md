[**breaking**] Bumped `rustls-platform-verifier` to `0.7.0` and `jni` to `0.22.4`
on Android, and removed the `jvm-getter` dependency. Android clients must now
call the new JNI function `org.matrix.rustsdk.Android.init(context)` with the
application `Context` before calling `init_platform`, e.g. by declaring:

```kotlin
package org.matrix.rustsdk

object Android {
    @JvmStatic
    external fun init(context: android.content.Context)
}
```
