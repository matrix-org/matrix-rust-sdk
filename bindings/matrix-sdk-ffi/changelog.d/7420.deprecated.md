`Client::is_login_with_qr_code_supported()` is deprecated in favour of
`Client::grant_login_with_qr_code_support()`. It was only ever meant for an
existing client that is logged in, and it now checks if that client can grant a
login by generating a QR code. As a result, it now also returns `false` if the
authorization server doesn't support the device authorization grant, and
returns an error if the authorization server metadata can't be fetched.
