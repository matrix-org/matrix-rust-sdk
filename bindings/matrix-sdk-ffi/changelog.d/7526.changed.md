[**breaking**] `ErrorKind` has two new variants, `KeyTooLarge` and `ProfileTooLarge`, so exhaustive
`switch`/`when` statements over it need updating. `Client::set_display_name` now returns
`ClientError::MatrixApi` for homeserver errors, or `ClientError::ContentScanner` for content scanner
errors. Callers that matched `ClientError::Generic` to detect homeserver rejections need to handle `MatrixApi` and `ContentScanner` too.
