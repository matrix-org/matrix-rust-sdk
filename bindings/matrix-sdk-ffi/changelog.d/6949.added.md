Expose URL previews on `Client`: `get_media_preview(url, ts)` returns the
homeserver-generated preview for a URL, or `None` if the homeserver offers
none. The preview is returned as a raw JSON string, because the OpenGraph
response has an open-ended set of fields (plus Matrix's `matrix:image:size`)
that a fixed structure would silently discard.

This makes the URL-preview support added in #6918 reachable from the
bindings, which is what [#4063] asked for on the client side.

[#4063]: https://github.com/matrix-org/matrix-rust-sdk/issues/4063
