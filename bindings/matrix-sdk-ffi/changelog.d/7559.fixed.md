Removed reference cycle in `SessionVerificationController` (SessionVerificationController -> Encryption -> Client -> 
Event handlers -> SessionVerificationController).

Also makes sure the `SessionVerificationController::listen_to_verification_request_changes` stops reading the stream
once `VerificationRequestState::Done` is received. Otherwise, it would run forever (or until it's canceled) because
nothing keeps a reference to its `JoinHandle` to manually drop it.
