Add an `HttpClient` that can be created with `HttpClient::from_settings()` from
the same `HttpSettings` and `RequestConfig` as a `Client`, without logging in.
This lets apps fetch resources before a session exists, using the same proxy,
user agent and TLS configuration as the SDK, and the same retries with
exponential backoff. `HttpClient::get_url()` returns the raw bytes of the
response. On failure, `HttpClientError::GetUrl` contains the HTTP status code
and the body of the error response, when the server responded.
