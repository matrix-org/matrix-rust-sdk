Keep the bundled SQLite private to the Apple `MatrixSDKFFI` framework. Its
symbols were exported from the static library, so an app that also links the
system `libsqlite3` could have the linker resolve the SDK's SQLite calls from the
system library instead. With the iOS 27 SDK, which exports newer functions such
as `sqlite3_set_errmsg`, the app then crashed at launch on older systems with
`Symbol not found: _sqlite3_set_errmsg`. The Swift build now binds those
references inside the library and hides the definitions.
