Added `Timeline::sendAttachment` and `Timeline::editWithAttachment`, which take the kind of attachment as an
`AttachmentKind` (image, video, audio, voice message or file) with the metadata that kind needs. `editWithAttachment`
replaces the attachment of a message the current user sent, or adds one to a message which had none: the new
attachment is uploaded through the send queue, then an edit carrying it is sent.
