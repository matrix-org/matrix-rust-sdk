Added a public API for delayed events ([MSC4140](https://github.com/matrix-org/matrix-spec-proposals/pull/4140)),
using the dedicated `/delayed_event` endpoint: `SendRawMessageLikeEvent::with_delay` turns a `Room::send_raw` call into
a delayed send, and `Room::send_delayed_state_event_raw` and `Room::update_delayed_event` cover state events and
cancelling / restarting / sending a scheduled event.
With the `unstable-msc4354` feature, a delayed message-like event can also be made sticky by calling `with_sticky_duration` before `with_delay`.
