A send queue request no longer wedges when refreshing the access token fails
for an undefinitive reason, such as a transport failure or a server 500. Only a 
refresh token the server actually rejects marks the request as unrecoverable 
and anything else leaves it queued to be sent again. A request the send queue 
wedged because the homeserver rejected the access token is now unwedged as soon 
as the session has a working one again.
