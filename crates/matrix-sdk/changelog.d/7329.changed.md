[**breaking**] `encryption::recovery::futures::*::with_passphrase` and
`encryption::secret_storage::futures::CreateStore::with_passphrase` have been
replaced with `encryption::recovery::futures::*::with_key` and
`encryption::secret_storage::futures::CreateStore::with_key`, taking a
`SecretStorageKey` rather than a passphrase.  This allows you to, for example,
enable recovery using a pre-generated key, rather than only being able to
generate the key while enabling recovery.  Recovery can still be enabled using a
passphrase by creating a `SecretStorageKey` from the passphrase.
