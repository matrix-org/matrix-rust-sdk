Expose `HttpSettings` and `HttpClient` on non-wasm targets, so an HTTP client
can be created outside of a `Client` while sharing its configuration and
behaviour. `HttpClient::with_settings()` builds one from `HttpSettings` (proxy,
user agent, timeouts, TLS verification and root certificates) and a default
`RequestConfig`. `HttpClient::send_raw()` sends an arbitrary HTTP request and
returns the body of the response, using the same retries with exponential
backoff and concurrent request limits as the Matrix API requests.
