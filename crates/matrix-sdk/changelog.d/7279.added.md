The widget driver now supports the `org.matrix.msc4533.rtc_livekit_get_token` and
`org.matrix.msc4533.rtc_livekit_delegate_delayed_leave` widget actions and capabilities from
[MSC4533](https://github.com/matrix-org/matrix-spec-proposals/pull/4533), which proxy the homeserver's
`/rtc/livekit/get_token` and `/rtc/livekit/delegate_delayed_leave` endpoints
([MSC4195](https://github.com/matrix-org/matrix-spec-proposals/pull/4195)) to the widget. `Capabilities` gained
the `rtc_livekit_get_token` and `rtc_livekit_delegate_delayed_leave` fields.
