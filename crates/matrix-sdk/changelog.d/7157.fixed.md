[**breaking**] The `device_authorization_grant` field of
`QrAuthMessage::LoginProtocol` is now an `Option<AuthorizationGrant>`. As per
MSC4108 this field is only present when the new device picks the
`m.login.device_authorization_grant` protocol. Previously an
`m.login.protocol` message without it failed to deserialize, so a device that
picked a different protocol got a decoding error instead of an
`m.login.failure` with the `unsupported_protocol` reason.
