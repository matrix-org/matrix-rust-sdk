Blocking a user no longer clears the entire event cache.

Previously, ignoring or unignoring a user cleared the event cache of every
room, which reset the latest event to `None` in all rooms, even in rooms with
no events from the blocked user. Now only the events sent by blocked users are
affected: they are filtered out when received, and the ones already stored are 
removed from the in-memorycaches and from the persistent store. Unblocking a 
user does not bring the removed events back, they can only come back 
through back-pagination.
