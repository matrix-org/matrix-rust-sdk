Support sticky events ([MSC4354](https://github.com/matrix-org/matrix-spec-proposals/pull/4354)) in the widget driver as per [MSC4407](https://github.com/matrix-org/matrix-spec-proposals/pull/4407), behind the `unstable-msc4354` feature flag. `Capabilities` gained `send_sticky_event` and `receive_sticky_event`. This requires the client to sync with simplified sliding sync.
