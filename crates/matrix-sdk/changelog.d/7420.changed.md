When generating a QR code to log in or to grant a login, the MSC4388 variant is
now used automatically if the `unstable-msc4388` feature is enabled and the
homeserver supports it, otherwise the MSC4108 variant is used. If the support
for MSC4388 can't be checked, the MSC4108 variant is only used if the
homeserver advertises support for it, otherwise the error is returned.
