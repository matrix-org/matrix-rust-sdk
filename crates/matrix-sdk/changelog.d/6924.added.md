Add `ClientBuilder::discover_server_support`, which reads the ways a server's
administrator can be reached from the `/.well-known/matrix/support` file that
server advertises, using the same HTTP settings `build` would. It stays
callable once a build has failed, so a client can name someone to contact after
failing to reach the homeserver at all. It needs a server name, so a builder
configured with `homeserver_url` alone fails with `InvalidServerName`.
