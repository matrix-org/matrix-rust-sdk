Add `sliding_sync::Version::Stable` for the stable version of MSC4186, with
`VersionBuilder::Stable` and `VersionBuilder::DiscoverStable`. `VersionBuilder::Discover`
picks the stable version if the homeserver advertises it, and the unstable one otherwise.
`Client::available_sliding_sync_versions` now reports the stable version too. Requests are
still sent to the unstable endpoint.
