Add `Client::find_expired_events()`, which returns the IDs of the non-state
events in the event cache that have expired according to the effective message
retention policy ([MSC1763](https://github.com/matrix-org/matrix-spec-proposals/pull/1763))
of their room, combining the room's `m.room.retention` state event with the
homeserver's retention limits. State events are never considered expired, and
nothing is returned if the homeserver doesn't support MSC1763.
