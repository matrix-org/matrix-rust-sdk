Add `ClientBuilder::disable_well_known_lookup`, which disables every `.well-known/matrix/client`
lookup performed by the built client, for deployments that must not emit any request to the 
well-known URI of their domain. When disabled, `Client::tile_server` returns `None`,
`Client::well_known_rtc_transports` returns an empty list, and `Client::discover_rtc_transports`
doesn't fall back to the well-known foci. Note that it doesn't affect the homeserver discovery
performed by `ClientBuilder::server_name`, which happens before the client is built.

Add `ClientBuilder::discover_rtc_transports` that discover the transports by first trying the new authenticated
 `GET /_matrix/client/v1/rtc/transports` API, and falls back to the `.well-known/matrix/client` lookup if allowed 
 by the client.
