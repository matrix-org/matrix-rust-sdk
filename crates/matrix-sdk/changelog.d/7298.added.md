`SyncSettings` now have a new boolean field `throttle_sync_loop`, true by default (to mimic the
previous behavior). When this flag is set, then all the sync v2 loops will be throttled to handle
at most one sync response per second. The involved methods are:

- `Client::sync()`
- `Client::sync_with_callback()`
- `Client::sync_with_result_callback()`
- `Client::sync_stream()`
