Add `RoomSendQueue::edit_with_attachment()`, which queues an edit replacing the media attachment of an already-sent media event. The new attachment is uploaded through the send queue like `send_attachment()` does, including while offline. Once the uploads complete, an `m.replace` edit carrying the new media is sent. The replacement must keep the media kind of the original event (an image stays an image, a video stays a video, and so on).
