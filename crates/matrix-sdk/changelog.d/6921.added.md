Add `RoomSendQueue::edit_with_attachment()`, which queues an edit turning an already-sent message into a media one: it replaces the attachment of a media message, with one of any kind, or adds one to a message which had none. The new attachment is uploaded through the send queue like `send_attachment()` does, including while offline. Once the uploads complete, an `m.replace` edit carrying the new media is sent.
