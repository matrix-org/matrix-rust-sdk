Add `OAuth::login_with_qr_code_support()` and
`OAuth::grant_login_with_qr_code_support()` to check which modes of QR code
login, scanning or generating a QR code, this client supports to log in or to
grant a login to a new client, respectively. They return a new
`QrCodeLoginSupport` type, or an error if the support can't be fetched from the
servers.
