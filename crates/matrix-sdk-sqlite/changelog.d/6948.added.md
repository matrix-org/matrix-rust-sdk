`SqliteStoreConfig::synchronous` sets [`PRAGMA synchronous`][pragma-synchronous]
on the store connections. The stores run in WAL mode, where the SQLite default
`FULL` means one `fsync` of the WAL file per transaction. `Synchronous::Normal`
syncs at checkpoints instead, which trades the durability of the most recent
transactions after a power loss or an operating system crash for fewer writes to
the storage device. The default stays `Synchronous::Full`.

[pragma-synchronous]: https://www.sqlite.org/pragma.html#pragma_synchronous
