`SpaceService` has two new cheap accessor functions for asking about the ancestors of a given:
* `joined_parent_ids_of_child()`: returns the room IDs of a
room or space's direct parent spaces that are known, without building the space graph or any expensive `SpaceRoom` instances.
* `top_level_ancestors_of()`: returns the IDs of
the top-level joined space(s) a room descends from.
