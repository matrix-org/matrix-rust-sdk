Clarify the docs of `LimitedUrl` and `QrCodeData::new_msc4388()`. `new_msc4388()`
encodes the normalised form of the base URL in the QR code, and
`LimitedUrl::as_bytes()` returns the exact bytes encoded in the QR code, which
MSC4388 requires to be used in the additional authenticated data. These can
differ from `LimitedUrl::as_str()` and `LimitedUrl::as_url()`, which return the
normalised URL.
