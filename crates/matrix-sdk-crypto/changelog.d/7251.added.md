Add experimental support for [MSC4350](https://github.com/matrix-org/matrix-spec-proposals/pull/4350), behind the `experimental-msc4350` feature.

A message sent with a bridge bot's device on behalf of a ghost user is no longer reported as coming from a mismatched sender if the ghost has an "impersonatable" device that the bot's device signed, the bot's device is cross-signed, and, if the ghost has cross-signing keys, the ghost's self-signing key signed that device.

`OlmMachine::set_impersonator_membership_check` can be used to also require the bot to be a member of the room.
