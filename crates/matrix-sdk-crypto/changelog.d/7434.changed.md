[**breaking**] `QrCodeData::new_msc4388()` now takes the homeserver base URL as a
`LimitedUrl` instead of a `Url`, and the `QrCodeCreationError::TooLongBaseUrl`
variant has been removed since the length is now checked when the `LimitedUrl`
is created. MSC4388 binds the secure channel to the exact base URL encoded in
the QR code, so the caller now decides whether, and how, the URL is normalised.
