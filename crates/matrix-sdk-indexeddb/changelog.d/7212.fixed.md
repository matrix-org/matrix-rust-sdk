Ensure that all stores of the `EventCacheStore` implementation are cleared when migrating
to `Version::V9`, as the changes from [#7072](https://github.com/matrix-org/matrix-rust-sdk/pull/7072)
modify the logic for determining whether an `Event` is stored out-of-band. Additionally,
the stores are cleared before adding the `out-of-band` index, as this leads to a more performant
migration.
