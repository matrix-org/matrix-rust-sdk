`StickyEventsUpdate::removed` is now a `Vec<StickyEventRemoval>` and its elements additionally carry the `tombstone` event that replaced the live one, when the reason is `RemovalReason::Replaced`. Furthermore, the new `StickyEvents::unexpired` returns both live events and unexpired tombstones. Finally, the new `sticky::is_tracked` makes the tracking condition for sticky events reusable.
