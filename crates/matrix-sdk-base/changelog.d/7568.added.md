Add `RoomInfoNotableUpdateReasons::SERVER_INITIATED_JOIN`, emitted when the
current user is joined to a room without this client performing the join
(e.g. an auto-accepted invite or an accepted knock), replacing an invite. It is
used to accept the inviter's room key bundle, as proposed in
[MSC4590](https://github.com/matrix-org/matrix-spec-proposals/pull/4590).
