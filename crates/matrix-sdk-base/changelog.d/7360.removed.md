[**breaking**] Remove `RoomInfo::fully_read_event_id`,
`Room::fully_read_event_id` and `RoomInfoNotableUpdateReasons::FULLY_READ`: the
`m.fully_read` marker can point to an event that isn't rendered in a timeline.
Use `matrix_sdk_ui::timeline::Timeline::fully_read_event_id` or
`Timeline::subscribe_fully_read_event_id` instead.
